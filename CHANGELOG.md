# Changelog

## [1.0.0] - 2026-10-12

**First public baseline** of Elhaj Drill Pulse. The earlier internal/prototype version identifier was **v32**; public version numbering intentionally starts with **v1.0.0**.

### Included
- Modern responsive Geo Workspace user interface.
- Drillhole visualization, logging and analytical tools.
- Trench location mapping, horizontal samples and multi-element assays.
- Surface sampling, geochemical statistics, PCA and narrative summaries.
- Anomaly/concentration surfaces and geospatial follow-up review.
- Optional internet satellite imagery, local-only data analysis and export.
- Android source plus an optional GitHub Actions **debug** APK workflow.

### Known limitations
- Interpolation is exploratory and sensitive to data density and parameters.
- External imagery requires internet access and use subject to imagery provider terms.
- Independent scientific verification and physical-device compatibility testing remain necessary.

# Security and privacy

Never add customer datasets, prospect maps with confidential coordinates, credentials, API keys, private imagery, or unpublished assay results to this public repository. `.gitignore` reduces mistakes but is not a security boundary.

If you notice a security/privacy bug, contact the repository maintainer privately through their GitHub contact information where possible rather than posting secrets in a public Issue. A leaked credential must be revoked, not merely deleted from the latest commit. Satellite providers may observe the displayed map area. No confidential data should be used when reproducing issues in public.
